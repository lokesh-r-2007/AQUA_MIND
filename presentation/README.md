# AquaMind AI — Hackathon Presentation Pitch Deck
**TCS AI Hackathon 2026 — Theme 3: AI for Impact (Sustainability)**

This directory contains the interactive presentation slide deck for the AquaMind AI project judging and evaluation session.

### How to View the Slides
1. Open [`index.html`](./index.html) in any modern web browser (Chrome, Edge, Safari, Firefox).
2. Keyboard Navigation:
   - **Right Arrow / Space / Page Down:** Next slide
   - **Left Arrow / Page Up:** Previous slide
   - **Home / End:** First / Last slide
   - **N:** Toggle presenter notes
   - **O:** Toggle slide overview grid
   - **F:** Toggle full screen
