# AquaMind AI — Documentation & Presentation
**TCS AI Hackathon 2026 — Theme 3: AI for Impact (Sustainability)**

This directory contains the project documentation, technical reports, and interactive presentation slide deck for the AquaMind AI platform.

---

### 1. Interactive Presentation Deck (GitHub Pages Ready)
- **[`index.html`](./index.html)** — Interactive 16:9 presentation slide deck for judging and evaluation.
- **[`style.css`](./style.css)** — Slide deck stylesheets and animations.
- **[`script.js`](./script.js)** — Presentation controller, keyboard shortcuts, and speaker notes.

#### Keyboard Shortcuts:
- **Right Arrow / Space / Page Down:** Next slide
- **Left Arrow / Page Up:** Previous slide
- **Home / End:** First / Last slide
- **N:** Toggle presenter notes
- **O:** Toggle slide overview grid
- **F:** Toggle full screen mode
